# Superstore Sales Analysis and Customer Clustering

This project explores and analyzes sales data from a fictional superstore to uncover key business insights. It includes visual exploration of regional sales patterns, product performance, and profit trends. It also applies clustering techniques (like K-Means) to segment customers based on their purchasing behavior.

## 🔍 Key Features

- Exploratory Data Analysis (EDA) with visualizations
- Insights on sales, profit, discounts, and regional performance
- Customer segmentation using clustering (e.g., K-Means)
- Data preprocessing and feature engineering for clustering
- Built using Python, Pandas, Matplotlib, Seaborn, and Scikit-learn

## 💡 Use Cases

- Identifying high-value customer segments
- Strategic decision-making for product and regional targeting
- Building foundations for targeted marketing campaigns
