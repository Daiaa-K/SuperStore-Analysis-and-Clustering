# Superstore Sales Analysis, Customer & Product Clustering

This project explores and analyzes sales data from a fictional superstore to uncover key business insights. It includes visual exploration of regional sales patterns, product performance, and profit trends. It also applies clustering techniques (like K-Means) to segment both **customers** and **products** based on their behaviors and performance.

In addition, it features **interactive dashboards** built using **Power BI** and **Tableau** for visualizing clustering results.

---

## 🔍 Key Features

- Exploratory Data Analysis (EDA) with visualizations
- Insights on sales, profit, discounts, and regional performance
- **Customer segmentation** using clustering (e.g., K-Means)
- **Product segmentation** using clustering (sales, profit, discount, quantity)
- Data preprocessing and feature engineering for clustering
- Dashboards for interactive exploration of clusters
- Built using Python, Pandas, Matplotlib, Seaborn, and Scikit-learn

---

## 📊 Dashboards

- 📌 **Power BI Dashboard**: Visualizes customer clustering results with interactive filters and charts
- 📌 **Tableau Dashboard**: Displays product clustering insights using KPIs and charts

---

## 💡 Use Cases

- Identifying high-value customer segments
- Spotting discount-sensitive or low-profit product groups
